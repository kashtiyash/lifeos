# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues or discussions. Use
the repository's private vulnerability-reporting feature in GitHub's Security
tab. Include the affected component, impact, reproduction steps, and any
suggested mitigation. Do not include real user data, credentials, or secrets.

If private reporting is unavailable, contact the repository maintainers
through a verified private channel before publishing details. A response-time
target and security contact must be configured before public launch.

## Supported versions

Only the latest deployed release is supported for security fixes.
